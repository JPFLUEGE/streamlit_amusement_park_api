
# Streamlit App: Near-Real-Time Waiting Times of Amusement Parks

A side project to get a first feel of Streamlit and explore its capabilities.

APIs being used: [Queue Times API](https://queue-times.com/pages/api)


## Why?

I wanted to explore more possibilities when it comes to reporting. The main motivation was to accomplish this using code, but also to take advantage of the great use case of a near-real-time API.

In reporting tools like Power BI, it can feel somewhat "hacky" to retrieve data from an API when it needs to be refreshed near real time. Power BI also limits the number of refreshes (depending on the license model), and its streaming dataset allows data to be sent to it, but not retrieved on its own, creating a need for a script to send data anyways.s
