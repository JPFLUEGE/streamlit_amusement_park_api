
# Streamlit App: Near-Real-Time Waiting Times of Amusement Parks

A side project to get a first feel of Streamlit and explore its capabilities.

APIs being used: [Queue Times API](https://queue-times.com/pages/api)


## Why?

I wanted to explore more possibilities when it comes to reporting. The main motivation was to accomplish this using code, but also to take advantage of the great use case of a near-real-time API.

In reporting tools like Power BI, it can feel somewhat "hacky" to retrieve data from an API when it needs to be refreshed near real time while code-based it is striaght forward as you just send a new API request or schedule it automatically within the app itself in an interval.

## Further developments

Potential further developments would be the caching of the selected park with automatically updating the waiting time data in a choosen interval with user feedback (e. g. waiting times fading in 'n out). 
While it is mobile optimized, the vertical view could be improved for the second graph and its legend involved.
